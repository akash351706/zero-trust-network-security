3. TRUST-SCORE FUNCTION (Section 2)
------------------------------------------------------------------------
T(x) = 1 - [ w1.y_hat(x) + w2.sigmoid(s(x)) + w3.D(x) ]

Weight search result (grid search against validation F1):
  w1 (Random Forest posterior)     = 0.55
  w2 (Isolation Forest, sigmoid)   = 0.40
  w3 (drift term, placeholder)     = 0.05
  Best F1 at this weighting        = 0.9997
  Classification threshold         = T(x) < 0.55 -> malicious

Note: D(x) held at 0 during this search (drift monitor not yet built -
planned for Phase 2). w3 is provisional and will be re-tuned once real
drift detection exists.

5. STACKED ENSEMBLE (RF + IF + LSTM-AE)
------------------------------------------------------------------------
Meta-learner: Logistic Regression (C=0.1)

Classification report (held-out test split):
              precision  recall  f1-score  support
  Normal        1.00      1.00     1.00     13468
  Attack        1.00      1.00     1.00     11725
  Accuracy                         1.00     25193

F1 score: 0.9997

Learned stacking weights:
  Random Forest signal    : 12.10
  Isolation Forest signal : 0.64
  LSTM-AE signal          : 0.013
  Intercept               : -6.42

Interpretation: Random Forest dominates because it already separates
this benchmark near-perfectly on its own (a known property of NSL-KDD,
also reflected in comparable published results - see baseline table
below). LSTM-AE and Isolation Forest are expected to contribute more
under concept drift or novel attack patterns not well represented in
this training data.

6. STATISTICAL SIGNIFICANCE TESTING (5-fold CV)
------------------------------------------------------------------------
Compared per-fold F1: Ensemble vs Random Forest alone vs Isolation
Forest alone (fresh meta-learner retrained on each fold's train split).

Per-fold F1 scores:
  Fold 1: RF-alone=0.9997  IF-alone=0.6352  Ensemble=0.9997
  Fold 2: RF-alone=0.9997  IF-alone=0.6352  Ensemble=0.9997
  Fold 3: RF-alone=0.9997  IF-alone=0.6352  Ensemble=0.9997
  Fold 4: RF-alone=0.9995  IF-alone=0.6352  Ensemble=0.9995
  Fold 5: RF-alone=0.9994  IF-alone=0.6352  Ensemble=0.9994

Mean +/- std across 5 folds:
  RF alone   : 0.9996 +/- 0.0001
  IF alone   : 0.6352 +/- 0.0000
  Ensemble   : 0.9996 +/- 0.0001

Paired significance tests:
  Ensemble vs RF alone : paired t-test  t=0.0004  p=0.9997
                         -> NOT significant (p>0.05)
                         Wilcoxon signed-rank  W=1.0000  p=1.0000
                         -> confirms no significant difference
  Ensemble vs IF alone : paired t-test  t=4865.7710  p=0.0000
                         -> SIGNIFICANT (p<0.05)

Interpretation: the ensemble is statistically indistinguishable from
Random Forest alone on this benchmark (expected, since RF already
near-saturates NSL-KDD performance), but is significantly and
substantially better than Isolation Forest alone. The honest claim
this supports: the stacked ensemble matches the strongest individual
model's accuracy while adding Isolation Forest's and the LSTM-AE's
complementary signals, which are expected to matter more under concept
drift or novel attacks not well represented in this static benchmark -
a claim to be tested more directly once Phase 2's drift monitor exists.
